# Senior Video Editor Colab

Google Colab workflow for narration + sentence images + exact sentence timing + FFmpeg export.

## Open in Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/adeelsandh078-a11y/senior-video-editor-colab/blob/main/Senior_Video_Editor_Colab.ipynb)

## Usage

1. Run Cell 1 and allow Google Drive.
2. Run Cell 2.
3. Run Cell 3.
4. Upload narration audio.
5. Upload images in sentence order.
6. Paste the exact narration script.
7. Click `CREATE PROJECT + AUTO SYNC`.
8. Click `EXPORT FINAL MP4`.

Exports save to:

`MyDrive/SeniorVideoEditor/exports`
